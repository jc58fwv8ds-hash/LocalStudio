# LocalStudio

Windows向けの、管理者権限を必要としないローカルAI開発ハーネスです。

## 現在の実装（0.16 preview）

- テンプレート外のローカル専用Windowsアプリ／ゲームを、Qwen2.5-Coderによる依頼固有の実装へ接続
- 生成したC# 5互換の単一ファイルWinFormsソースを、決定的な安全検査と実コンパイルへ通し、失敗理由を最大3候補×各20分の範囲でAIへ戻して自律修復
- モデル応答をストリーミング受信し、受信文字数と開始時から固定した最大時間をGUIへ表示
- 修復時は全ソースを再出力させず、最大6件の一意完全一致置換だけを生成して曖昧一致・無変更を拒否し、適用後に全検査と実コンパイルを再実行
- ネットワーク、外部プロセス、シェル、レジストリ、P/Invoke、Reflection、危険な動的コード、管理者権限を生成前後で禁止
- 合格候補だけを実在するWindows EXEとして保存し、`asInvoker / uiAccess=false` を埋め込み
- コード不良とPC側のビルド環境不良を分離し、環境問題で同じ再生成を繰り返さない
- 新規Windows実装も機能ごとのGUI操作確認へ接続し、実操作前は「操作確認待ち」と正直に表示
- テトリス要求では、盤面・7形状・衝突付き操作・ライン消去・可視得点・可視ゲーム終了・R再開に加え、要求時は独立した次ピース状態と可視プレビューを保存前に検査

- サジェストをWeb既定値から多分類判定へ変更し、Windowsゲーム、GAS、Agent、Windows EXEを用途から識別
- 形式を判断できない依頼はWebへ決め打ちせず、不足している判断材料と現在の選択を表示
- おすすめが現在未対応の場合は、適した形式とLocalStudioの実装可能範囲を分けて説明
- 出力形式を「Webアプリ（ブラウザー）」と「Windowsアプリ（EXE）」へ明確に分離し、依頼文から適した形式を提案
- 文字数・行数カウンターを、ブラウザーを使わない実際のWindows EXEとして生成・検証
- Windows EXEへ `asInvoker` マニフェストを明示的に埋め込み、データは現在ユーザーのLocalAppDataだけへ保存
- EXE生成プロセスは直接・非表示で実行し、コマンド画面や管理者権限を要求しない
- 生成Webアプリに内部要件IDや「実装対象の機能」を表示せず、追跡情報はLocalStudio所有の検証記録に分離
- 設計・生成中の所要時間は、開始時から変わらない「最大○分程度」と経過時間だけを表示

- プロジェクト画面から生成アプリを直接開き、要件ごとに「確認済み」「問題あり」をGUIで記録
- LocalStudio所有の `verification-plan.json` が、コードを読まなくても実行できる短い確認手順を表示
- 全機能を確認した場合だけ `user-verified` へ昇格し、一部確認・問題あり・再確認必要を区別
- コード、要件、確認計画のSHA-256が変わると以前の操作確認を自動的に無効化
- 検証台帳の操作をLocalStudioプロジェクト領域内に限定し、ジャンクション・シンボリックリンク経由の参照を拒否

- 価格計算・Todo・ピンボール以外のローカルWebアプリを、固定テンプレートへ偽装せずQwen2.5-Coderで要件固有に新規実装
- 新規実装は本文HTMLとJavaScriptだけをAIに生成させ、文書シェル、CSP、外観、非表示の要件検証記録はLocalStudioが所有
- 生成候補は最大3回。検証識別名を具体的な修正指示へ翻訳し、無制限ループを防止
- 制御文字、危険API、外部通信、要件根拠、既知の文字数・行数・自動保存・消去契約を決定的に検査
- 同じモデルによる自己レビューを完全動作保証に使わず、`structural-preview`（構造確認済み・操作確認待ち）として保存
- 実ブラウザ試験で、テンプレート外の文字数カウンターについてリアルタイム集計、自動保存、再読込、消去を確認

- WPFによる日本語セットアップGUI
- 公式Ollama Windows portable ZIPの取得
- 公式Windowsインストーラーでユーザー領域へ導入済みのOllamaを検出・再利用
- 公式SHA-256一覧との照合後にのみ展開
- Ollamaを非表示プロセスとして起動し、GUIからAPIを直接利用
- 既存Ollamaを使う場合も、LocalStudio専用の動的loopbackポートとローカル専用モードで起動
- GUI上でQwen2.5-Coderモデルを選択・取得
- 同一の無変更操作を2回で遮断する実行台帳
- 管理者起動を要求しない `asInvoker` マニフェスト
- 話し言葉からアプリ・GAS・エージェントの型付き設計案を作成
- Agent設計は実働アプリと区別し、`design-scaffold / not-started` と明示
- Agent設計保存時に外部通信・送信権限を除去し、権限未付与・実行無効を独立検証
- `working-implementation`、独立検証、権限レビュー、ロールバック試験を完成条件として保存
- 確認済み設計案からローカルプロジェクト雛形を原子的に作成
- Presentation / Application / Domain / Infrastructureの依存方向テスト
- LocalStudio所有プロセスだけを使用する動的Ollamaポート
- エージェント要求権限のallowlistと初期実行禁止
- 新規プロジェクトのaccepted baselineとハッシュmanifest
- モデル設定の永続化と全工程での共有
- 長時間の取得・推論・作成処理の中止
- スタジオ入力の500msデバウンス自動保存と次回起動時の復元
- 既存プロジェクトを新しい順に表示し、保存フォルダーを開けるプロジェクト画面
- 作成完了時の保存先表示と、同じ設計案からの誤った連続重複生成の防止
- セットアップ中の転送量、速度、経過時間、推定残り時間表示
- 設計・生成中の現在段階、経過時間、開始時から固定した最大所要時間目安
- LocalStudio管理プロジェクトだけを対象にした厳密な安全編集セッション
- read-before-write、完全一致1箇所置換、UTF-8/Unicode破損検査
- 変更前run snapshot、検証ゲート、rollback、検証後のaccepted baseline更新
- パストラバーサル、reparse point、`.localstudio`制御領域へのモデルアクセス拒否
- App種別で依存不要の実働ローカルWebアプリを生成
- タスク管理と価格・割引・消費税計算を別々の要件／実装／検証器で生成
- 外部通信を必要としない未知のアプリ設計を、固定テンプレートへ置き換えず依頼固有に生成
- CSP、外部リソース禁止、危険な動的HTML/コード禁止、アクセシビリティを独立検証
- 生成時の検証証拠を `.localstudio/verification` に保存
- テンプレート出力のファイル数・サイズ・重複パス・Unicode境界
- タスク追加、編集、完了、削除、絞り込み、localStorage永続化のE2E動作テスト
- 話し言葉から安全なWindowsゲームblueprintを作るオフライン経路
- WPFピンボールの埋め込みテンプレートと19項目のWindowsソース検証
- 安全編集セッションによる新規ファイル作成、検証、rollback、baseline昇格
- 生成後のReleaseビルドと物理ロジック試験を使った監督ワークフロー

- 大規模アプリを2～64個の開発単位DAGへ分け、循環、欠落前提、レイヤー逆依存を生成前に拒否
- ready frontierの1単位だけを生成し、合格済み依存成果物だけを後続へ渡す再開可能な状態機械
- 単位ごとに最大4回、実行中断回復、原子的状態保存、直前状態バックアップ、SHA-256成果物指紋
- 単位成果物の件数・容量・拡張子・相対パス・担当レイヤーを検査し、候補領域へ隔離保存
- 依存単位との検証ワークスペース合成時に同一パスの異内容競合を拒否
- モデル生成の`.csproj`を許可済みSDK構文へ限定し、`Target`、`Exec`、`Import`、条件式、外部パッケージ等を拒否してから実ビルド
- `manual-spike`を静的検査だけで合格扱いにせず、実機確認が必要な状態として保持

## 非管理者要件（変更不可）

アプリ、Ollama、モデル、ログ、実行状態はすべて次の配下だけに保存します。

`%LOCALAPPDATA%\LocalStudio`

次の操作は禁止しています。

- UAC昇格要求
- Windowsサービスの登録
- `Program Files` への書き込み
- HKLMレジストリの変更
- システムPATHまたは端末全体の環境変数変更
- 社内ポリシー回避の試行

端末ポリシーに拒否された場合、GUIは理由を表示して安全に停止します。

## 開発時の確認

依存パッケージは追加していません。ビルドには.NET 10 SDKを使います。

```powershell
dotnet build SafeLocalHarness.slnx --configuration Release
dotnet run --project tests\SafeLocalHarness.SmokeTests --configuration Release
```

自己完結型の配布物は `win-x64` 向けに発行します。利用者PCに.NET SDKやランタイムは不要です。
